This project provides filtering, analysis of build permits retrieved from NYC Open Data.

NYC Open Data DOB NOW: Build - Approved Permits JSON Editor Online

NYC Open data is an online platform that publishes free, public data generated by New York City agencies and organizations.

The DOB NOW: Build - Approved Permits data set is a list of all approved construction permits in DOB NOW except for Electrical, Elevator, and Limited Alteration Application (LAA) which have their own datasets.

DOB NOW: Build - Approved Permits is important because it is the legal authorization required to perform construction or renovation work in NYC. It ensures projects comply with strict safety and zoning codes, helps avoid hefty fines or stop-work orders, and keeps a transparent, easily accessible public record of all structural modifications.

In the information page: You will be able to work through the data set and search for certain areas you wish to see.

In the analysis page: You will be able to see seach location through a map and see charts with how much areas has permits.
